# RISC-V SoC Tapeout Program – My VSD Journey 

Welcome to my personal documentation of the **VLSI System Design (VSD) RISC-V SoC Tapeout Program**!  
This repository tracks my progress week-by-week as I go from RTL to GDSII using open-source tools, as part of India’s largest collaborative silicon design initiative.


---

## 📅 Week 1 RTL Design and Synthesis Fundamentals
RISC-V Reference SoC Tapeout Program
Week 1: RTL Design and Synthesis Fundamentals

Welcome to Week 1 of the RISC-V Reference SoC Tapeout Program! This week focuses on building strong foundations in RTL design, synthesis methodologies, and optimization techniques essential for successful ASIC design.

# Day 1 - Introduction to Verilog RTL Design and Synthesis

Learning Objectives:

    Understand the fundamentals of RTL design flow
    Learn Verilog syntax and coding best practices
    Introduction to open-source synthesis tools
    Hands-on experience with Icarus Verilog and Yosys

Key Topics:

    RTL design methodology
    Verilog HDL basics
    Simulation vs synthesis
    Gate-level representation
    Basic synthesis flow

Tools Covered:

    Icarus Verilog (iverilog)
    GTKWave
    Yosys synthesizer

# Day 2 - Timing Libraries, Hierarchical vs Flat Synthesis and Efficient Flop Coding Styles

Learning Objectives:

    Understand timing library concepts and their importance
    Compare hierarchical and flat synthesis approaches
    Learn efficient flip-flop coding techniques
    Master clock domain considerations

Key Topics:

    Liberty (.lib) files and timing models
    Hierarchical synthesis benefits and challenges
    Flat synthesis trade-offs
    Flip-flop variants and coding styles
    Clock tree considerations
    Setup and hold time analysis

Practical Skills:

    Working with timing libraries
    Choosing appropriate synthesis strategies
    Writing efficient sequential logic

# Day 3 - Combinational and Sequential Optimizations

Learning Objectives:

    Master combinational logic optimization techniques
    Understand sequential logic optimizations
    Learn resource sharing and logic minimization
    Explore constant propagation and dead code elimination

Key Topics:

    Boolean optimization techniques
    Resource sharing strategies
    Sequential optimizations (retiming, state encoding)
    Constant propagation
    Unused logic removal
    Critical path optimization

Lab Focus:

    Optimization case studies
    Before/after synthesis comparisons
    Area vs timing trade-offs

# Day 4 - GLS, Blocking vs Non-blocking and Synthesis-Simulation Mismatch

Learning Objectives:

    Understand Gate-Level Simulation (GLS) importance
    Master blocking vs non-blocking assignment concepts
    Identify and resolve synthesis-simulation mismatches
    Debug common RTL coding pitfalls

Key Topics:

    Gate-Level Simulation methodology
    Blocking (=) vs non-blocking (<=) assignments
    Race conditions and simulation deltas
    Synthesis-simulation mismatch root causes
    Debugging techniques and best practices

Critical Skills:

    Writing simulation-synthesis consistent code
    GLS verification techniques
    Debugging mismatches

# Day 5 - Optimization in Synthesis

Learning Objectives:

    Advanced synthesis optimization strategies
    Constraint-driven synthesis techniques
    Power, performance, and area (PPA) optimization
    Multi-objective optimization approaches

Key Topics:

    Synthesis constraints and their impact
    Timing-driven optimization
    Power-aware synthesis techniques
    Area optimization strategies
    Multi-Vt cell usage
    Clock gating implementation
    Advanced optimization algorithms

Advanced Techniques:

    Custom optimization scripts
    Constraint prioritization
    PPA trade-off analysis
